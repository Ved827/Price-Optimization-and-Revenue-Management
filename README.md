The project aims to optimize pricing strategies for Copa Cruises, a dining and sightseeing cruise company, using historical contract data for group bookings. The analysis involves determining a single price per person that maximizes expected revenue per event and estimating the total annual revenue with this pricing. Additionally, the project explores price segmentation based on customer type, location, or booking behavior to identify revenue-maximizing prices for each segment. Further considerations include evaluating the impact of varying costs and group sizes on pricing strategies.
